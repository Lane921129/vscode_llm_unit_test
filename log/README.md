# 本機 Agent 與執行日誌

此目錄專門放置不應提交的本機工作階段日誌，例如 Agent 執行紀錄、暫存診斷、模型連線除錯輸出與人工檢查筆記。

- 此目錄內容由 `.gitignore` 排除；只有本說明檔納入版本控制。
- 絕不可寫入 API Key、Token、密碼、完整 Authorization header 或含密鑰的網址。
- 可提交的專案變更摘要維持寫在根目錄 `CHANGELOG.zh-TW.md`；規則與自動維護說明也維持為根目錄的版本化文件，不混入本機日誌。
- `test/result/` 是使用者可查閱的測試產物，不會因為本目錄而被搬移或刪除。
- `OPEN_SOURCE_V1_TODO.md` 是每次開始實作時使用的一個月開源 v1.0 待辦清單；它同樣是本機、被忽略的工作計畫。完成項目時，請在原項下寫入日期、驗證、限制與 commit，不要寫入密鑰或使用者資料。
