## 尚未交付的完整計畫範圍

靜態型態樹與 typed caller 全程傳輸、容器／Optional／複雜型態 baseline、受限制的 setup／Mock adapter、多步狀態案例、逐案 coverage 回饋、完整 TargetSpec、case-delta 與 AST 修改範圍、能力導向策略及代表性資格、survivor 優先選測／快取、共用 QualityPolicy、逐筆輸入 UI／設定遷移、主控與舊路徑重構、固定模型 A/B／corpus／保留評估集、外部引擎真實環境與遠端 CI 驗收，均保留在原計畫中。

本次的安全 codec 不會補回 caller 先前經一般 JSON 傳輸遺失的 tuple／dict key 等型態；typed `input_before` 與歷史 repr 欄位的跨表示一致性尚未全面驗證，正式 producer 使用呼叫前值，毀損資料仍須由後續執行 gate 拒絕。只支援受管理的 `threading.Thread`，直接低階 `_thread` 啟動列為受阻擋。程序內 guard 不等同作業系統 sandbox。這些限制不得藉放寬 assertion、coverage 或 mutation gate 掩蓋。
