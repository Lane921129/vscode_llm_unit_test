## 如何看進度

| 訊息 | 意義 |
| --- | --- |
| structure passed | 測試結構、目標呼叫與斷言證據符合目前檢查，還未完整驗收 |
| structure rejected | 生成測試未通過檢查，原因現在直接顯示；交 Writer 修訂，額度用盡則停止本候選 |
| scenarios observed | 已記錄本次執行情境及識別 |
| coverage measured | 覆蓋率已量測，不代表達標 |
| validation passed | 這份生成測試已成功隔離執行 |
| executable-baseline checkpointed | 已保存可執行測試及當時審查狀態；再次出現可能是在更新審查狀態 |
| model-request requested／completed | 已送出請求／收到回覆；尚未證明內容有效 |
| reviewer invalid-response | 回覆格式或引用／目標契約有問題，不能當成有效審查 |
| reviewer unavailable | 本次沒有有效審查；保留可執行測試，仍繼續工具量測 |
| validation accepted | 接受為可繼續量測的候選，不是完整通過 |
| builtin | 內建突變引擎正在執行原始基線及突變副本，完成後回報計數 |

`structure` 包含語法／unittest 結構、import 與 target binding、呼叫簽名、有效斷言、安全政策及 Trace 證據檢查。常見拒絕包括缺少 `test_`、只斷言無關常數、目標被重新定義／mock、參數不符，以及同一已觀測輸入的預期值不一致。這不是受測原程式已被證明有 bug。
