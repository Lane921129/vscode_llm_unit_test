# Code of Conduct

## Our commitment

We want this project to be a welcoming, respectful space for everyone,
regardless of experience level, identity, background, or model/provider choice.

## Expected behaviour

- Be constructive, specific, and respectful in issues, reviews, and discussions.
- Assume good intent and ask for clarification before escalating disagreement.
- Protect privacy: redact credentials, personal data, proprietary code, and
  sensitive model outputs.
- Focus criticism on code, documentation, and reproducible behavior rather
  than people.

## Unacceptable behaviour

- Harassment, discrimination, threats, personal attacks, or deliberate
  intimidation.
- Publishing another person's private information, credentials, or proprietary
  source code without permission.
- Deliberately bypassing repository safety checks or encouraging unsafe use of
  provider credentials.

## Reporting

Report conduct concerns privately to the repository maintainer through the
GitHub profile. Do not open a public issue when a report would expose personal
or sensitive information. Reports will be reviewed fairly and handled with as
much confidentiality as practical.
